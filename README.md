# You' Com — Site commercial 360°

Site Node.js/Express avec formulaires de devis et audit, back-office prospects, PostgreSQL Render, SEO technique, sitemap, robots.txt, pages services, offres, blog et pages légales.

## Variables d'environnement
- `DATABASE_URL`
- `SITE_URL`
- `ADMIN_USER`
- `ADMIN_PASS`
- `LEAD_EMAIL` (optionnel)
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM` (optionnels pour les emails automatiques)
